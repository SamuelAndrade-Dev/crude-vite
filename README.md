# React + Vite + CRUD

## Objetivo do projeto

Construir uma interface de usuário consumindo uma API REST para realizar operações completas de CRUD

## Requisitos

- Node v26.7.0
- Yarn

## Biliotecas utilizadas:

- **React + Vite**
- **Taillwind CSS**
- **Axios**
- **Tanstack Form**

## Microserviço / API Utilizada:

- Endpoint `https://jsonplaceholder.typicode.com/users`

## Para executar em modo desenvolvimento:

```
yarn install

yarn dev

```
